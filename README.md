# Muhāsib (محَاسِب)

Yog'och mahsulotlari savdosi va ombor qoldig'ini kunma-kun hisoblaydigan, internetsiz ishlaydigan telefon ilovasi.

**Ilovani ochish:** https://dilshod-coder-dotcom.github.io/Calculator/
Telefonda Chrome'da oching → ⋮ → «Bosh ekranga qo'shish».

- Ish joylari: har bir ish joyi (boshqaruvchisi bilan) alohida hisob, qoldiq, nasiya va hisobot; «Barcha ish joylari» umumiy ko'rinishi
- Sotuv: m³, m², pogon metr, dona, qop; donalab, to'g'ridan yoki kuzov bo'yicha; tez chegirma (%, karrali summalar, yaxlitlash)
- Mijoz, haydovchi, kafil: so'nggi qo'ng'iroqlar yoki kontaktlardan tanlash (APK)
- Karta to'lovi: qaysi kartangizga tushgani, mijoz kartasi (skaner), chek rasmi yoki SMS tasdig'i
- Nasiya: shartnoma (jadval, xaridor, kafil, surat, imzolar), 3 kun oldin eslatma, «halol bo'ldi / bo'lmadi», muddatni cho'zish, shartnoma va dalolatnoma PDF
- Qoldiq: kirim, sotuvdan avtomatik ayirish, sanab tuzatish, kam qolganda ogohlantirish; har bir tovar va ish joyi bo'yicha ombordagi qiymat va sotilgan summa
- Hisobot: kunlik, oylik, yillik; Excel (.xlsx) va PDF; oy yopish va zaxira; boshqaruvchi telefonidan faylni qabul qilish

Ma'lumotlar faqat telefonda saqlanadi, bu repository'ga hech qachon tushmaydi.

`src/index.src.html` — kutubxonalarsiz manba fayl; `index.html` — tayyor, hammasi ichiga joylangan versiya.

## Android ilova (APK)
`apk/` papkasida Capacitor loyihasi bor. GitHub Actions («APK (Muhāsib)») imzolanmagan APK yig'adi; u GitHub'dan tashqarida saqlanadigan kalit bilan imzolanadi. APK ochiq tarqatilmaydi.
