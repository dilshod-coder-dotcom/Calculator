# Muhāsib (محَاسِب)

Ish joylari, xomashyo, mahsulot va sotuvni hisoblaydigan, internetsiz ishlaydigan telefon ilovasi (1.5).

**Ilovani ochish:** https://dilshod-coder-dotcom.github.io/Calculator/
Telefonda Chrome'da oching → ⋮ → «Bosh ekranga qo'shish».

- 4 ta ish joyi (nomlari foydalanuvchiniki): har birida xomashyo va mahsulot qoldig'i alohida
- Nomlar ro'yxati (Taxta, Shpunt, Plintus, Reyka, Vassa, Skameyka, DVP, DSP, Vogonka va o'zingiz qo'shganlar); har bir nom ichida turlar: turi + o'lchami + soni + narxi
- Kiritish (xomashyo yoki tayyor mahsulot), mahsulot chiqarish (qaysi ish joyidagi xomashyodan qancha), ish joylari orasida ko'chirish
- Sotuv: bitta chekda xomashyo ham, mahsulot ham; omborga hali kiritilmagan tovarni ham sotish (qoldiq minusda turadi), qoldiqdan ko'p bo'lsa tasdiq so'raladi
- Mijoz, haydovchi, kafil (so'nggi qo'ng'iroqlardan), karta to'lovi va tasdig'i, chegirma
- Nasiya: shartnoma, jadval, surat, imzolar, eslatma, «halol bo'ldi / bo'lmadi», shartnoma va dalolatnoma PDF
- Hisobot: davr (bugun … sanadan sanagacha), ish joyi, xomashyo/mahsulot, nomlar va turlar bo'yicha sotildi va qoldi, kiritilmaganlar, harakatlar tarixi; Excel va PDF; oy yopish va zaxira
- 1.4 dagi ma'lumotlar birinchi ochilishda yangi tuzilishga o'tkaziladi

Ma'lumotlar faqat telefonda saqlanadi, bu repository'ga hech qachon tushmaydi.

`src/index.src.html` — kutubxonalarsiz manba fayl; `index.html` — tayyor, hammasi ichiga joylangan versiya.

## Android ilova (APK)
`apk/` papkasida Capacitor loyihasi bor. GitHub Actions («APK (Muhāsib)») imzolanmagan APK yig'adi; u GitHub'dan tashqarida saqlanadigan kalit bilan imzolanadi. APK ochiq tarqatilmaydi.
