# Calculator

Yog'och mahsulotlari savdosi va ombor qoldig'ini kunma-kun hisoblaydigan, internetsiz ishlaydigan telefon ilovasi.

**Ilovani ochish:** https://dilshod-coder-dotcom.github.io/Calculator/
Telefonda Chrome'da oching → ⋮ → «Bosh ekranga qo'shish».

- Sotuv: m³, m², pogon metr, dona, qop; donalab (o'lcham bo'yicha), to'g'ridan yoki kuzov bo'yicha
- Qoldiq: kirim, sotuvdan avtomatik ayirish, sanab tuzatish, kam qolganda ogohlantirish
- Hisobot: Excel (.xlsx) va PDF, oy yopish va zaxira

Ma'lumotlar faqat telefonda saqlanadi, bu repository'ga hech qachon tushmaydi.

`src/index.src.html` — kutubxonalarsiz manba fayl; `index.html` — tayyor, hammasi ichiga joylangan versiya.
